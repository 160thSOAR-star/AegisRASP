## 4. 已执行的校验（1.0.1 发版复核）

1. **Native 编译**：14 个 C 文件在 `aarch64-linux-android35` 与 `x86_64-linux-android35` 下均 `-Wall -Wextra` **零警告、零错误**通过。本轮 `buildNdkBuildRelease[arm64-v8a]` / `[x86_64]` 确实重编译了改动文件；另外在临时目录用同一份 `Android.mk` + `Application.mk` 做了一次**全量干净编译**（28 个编译单元，0 warning / 0 error），以排除「增量缓存掩盖警告」的可能。
2. **Native 链接**：`llvm-readelf --dyn-syms` 复核，两个 ABI 的 `libaegisrasp.so` 动态符号表中 `GLOBAL DEFAULT` 函数仅有 `JNI_OnLoad`，其余符号被 `-fvisibility=hidden` 隐藏。
3. **JNI 契约**：`dexdump` 复核 Kotlin 侧 5 个 native 方法的描述符与 `rasp_jni.c::g_methods` 逐字符一致：
   `runDetect:(Ljava/lang/String;Ljava/lang/String;Ljava/lang/String;Lcom/rasp/detect/RaspNative$EvidenceSink;)Ljava/lang/String;`、
   `submitEvidence:(Ljava/lang/String;)V`、`cancelDetect:()V`、`nativeVersion:()Ljava/lang/String;`、
   `readProperty:(Ljava/lang/String;)Ljava/lang/String;`——同时说明 R8 未裁掉 `-keep class com.rasp.detect.** { *; }`。
4. **检测项打包确认**：字符串检索确认两个 ABI 的 `.so` 均含 `MNT-008`、`MNT-009`、`KRN-006`、`KRN-007`、`INJ-005`、`AHK-005`、`AHK-006`、`FOPS-001`、`ZYS-007` 及版本串 `aegis-rasp/1.0.1`；`ZYS-008` 按设计是 Java 层探针，已在 `classes.dex` 中确认存在。
5. **版本号**：`aapt2 dump badging` 复核 `versionCode='3'`、`versionName='1.0.1'`、`minSdkVersion:'30'`、`targetSdkVersion:'35'`、`package: name='com.rasp.detect.aegis'`。
6. **应用内日志**：UTF-8 检索确认 `classes.dex` 含 1.0.1 新条目的四条文案，且 1.0.1-rc / 1.0.0 历史条目仍在（与 `AboutScreen.kt` 源码一致）。
7. **打包内容**：两个 ABI 的 `libaegisrasp.so`、白名单 asset、dex 均在 APK 内；均无 `armeabi-v7a` / `x86` 残留。
8. **权限**：`aapt2 dump permissions` 只有 AndroidX 自动注入的 `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`，未申请 `INTERNET`。
9. **签名**：`apksigner verify -v --print-certs` 通过 v2 校验（v1/v3/v3.1/v4 均为 false，与 1.0.0 一致）；证书 SHA-256 与 1.0.0 / 1.0.1-rc 相同 → 已装旧版可直接覆盖升级。

## 6. 已知限制

1. **跨进程 procfs 读取受限**：普通应用读取 init / system_server 的 `mountinfo`、`status`、`root/...` 通常 `EACCES`，相关检测项以 `available=false` 标注，不能视为「安全」。
2. **非 SDK 接口**：`ZYS-006` 的 binder 直查依赖 `ServiceManager` / `IPackageManager`，被隐藏 API 策略拦截时降级为不可用。
3. **内核侧可读性**：`KRN-005`（kallsyms）、`BPF-002`（fdinfo）、`SEL-002`（selinuxfs）在部分设备上不可读，同样只做不可用标注。
4. **检测项可被整体关闭**：设置页关闭某一项后，该项不产生证据也不参与打分（`counts.total` 会相应减少）。
5. **快速模式改变报告形状**：快速模式跳过 MNT-002/003/006 与 BPF-003，进程扫描上限 700→220、KRN-001 采样 240→80；做 Root 环境验收请使用完整模式。
