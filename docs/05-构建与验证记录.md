## 4. 已执行的校验（2.0.0-beta 发版复核）

1. **Native 编译**：**15 个 C 文件** × 2 ABI = **30 个编译单元**，`-Wall -Wextra` **零警告、零错误**。
   （用同一份 `Android.mk` + `Application.mk` 在隔离目录做全量干净编译，排除增量缓存掩盖警告。）
2. **16 KB 页对齐**：`llvm-readelf -l` 复核两个 ABI 的 4 个 `LOAD` 段全部 `Align = 0x4000`；
   APK 内 `.so` 的 zip 数据偏移也落在 16 KB 边界。
3. **Native 链接**：动态符号表 `GLOBAL DEFAULT` 仅 `JNI_OnLoad`，其余符号由 `-fvisibility=hidden` 隐藏。
4. **JNI 契约**：`dexdump` 复核 5 个 native 方法描述符与 `g_methods` 一致（`runDetect` / `submitEvidence` /
   `cancelDetect` / `nativeVersion` / `readProperty`）；`runDetect` 为 **4 个 String + EvidenceSink**。
5. **版本号**：`aapt2 dump badging` 复核 `versionCode='6'`、`versionName='2.0.0-beta'`、
   `compileSdkVersion='36'`、`targetSdkVersion:'36'`、`minSdkVersion:'30'`、`platformBuildVersionName='16'`。
6. **检测项打包确认**：两个 ABI 的 `.so` 均含 `MNT-008/009`、`KRN-006/007`、`INJ-005`、`AHK-005/006`、
   `FOPS-001`、`ZYS-007` 与版本串 `aegis-rasp/2.0.0-beta (native, api36)`；`ZYS-008` 在 `classes.dex` 中。
7. **打包内容**：77 个条目；两个 ABI 的 `libaegisrasp.so`、白名单 asset、dex 均在 APK 内；无 32 位残留。
8. **权限**：仅 AndroidX 自动注入权限，无 `INTERNET`。
9. **签名**：`apksigner verify -v --print-certs` 通过 v2 校验，证书 SHA-256 与 1.0.0–1.0.3 完全一致。
10. **Lint**：`lintVitalRelease` 通过。
11. **⚠️ 没能验证的（必须知道）**：`AGP 8.7.3 + compileSdk 36` 是 Google **未支持**的组合，
    靠 `android.suppressUnsupportedCompileSdk=36` 绕过 AGP 守卫。构建 / lint / 签名都过了，但
    **d8/R8/lint 的 API 36 行为变更检查并没有被真正验证**。升级 AGP（8.9+，需 Gradle 8.11+）
    已列入 `ROADMAP.md` 技术债 #13。

> **本版性质**：以上第 1–10 项都在 2.0.0-beta 上重新执行过。代码行为相对 1.0.3 **只改了共享页释放
> （`munmap`）与内存屏障**，检测判据未动。
>

## 6. 已知限制

1. **跨进程 procfs 读取受限**：普通应用读取 init / system_server 的 `mountinfo`、`status`、`root/...` 通常 `EACCES`，相关检测项以 `available=false` 标注，不能视为「安全」。
2. **非 SDK 接口**：`ZYS-006` 的 binder 直查依赖 `ServiceManager` / `IPackageManager`，被隐藏 API 策略拦截时降级为不可用。
3. **内核侧可读性**：`KRN-005`（kallsyms）、`BPF-002`（fdinfo）、`SEL-002`（selinuxfs）在部分设备上不可读，同样只做不可用标注。
4. **检测项可被整体关闭**：设置页关闭某一项后，该项不产生证据也不参与打分（`counts.total` 会相应减少）。
5. **快速模式改变报告形状**：快速模式跳过 MNT-002/003/006 与 BPF-003，进程扫描上限 700→220、KRN-001 采样 240→80；做 Root 环境验收请使用完整模式。

## 7. 复现提示

- 依赖仓库已在 `settings.gradle.kts` 中配置阿里云镜像优先、官方源兜底。
- 若 wrapper 下载缓慢，`gradle/wrapper/gradle-wrapper.properties` 的 `distributionUrl` 已是腾讯云镜像。
- 工作区路径含中文时，必须保留 `gradle.properties` 中的 `android.overridePathCheck=true`；若 native 构建仍异常，可将工程目录以目录联接（junction）映射为纯 ASCII 路径后再构建（本次构建即通过 `E:\aegis-build` 联接完成，产物落回 `E:\安卓检测项目`）。
